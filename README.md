这是给个人电脑使用的本地知识库工作台，采用暖白配色，保留蓝旗鱼 Logo、AI 生成的分类头像、总控台布局、滨水 3D 知识之城和“知识团队”分类图谱。安装包不附带打包电脑上的知识文件、账号、聊天记录、模型密钥或仓库路径；首次打开后，选择你自己电脑上的 Markdown／Obsidian 仓库，页面才会根据你的文件显示真实数据。

## 安装与打开（Windows）

1. 把 ZIP **完整解压**到一个你有写入权限的文件夹。不要直接在压缩包里运行，也不要放在系统保护目录。
2. 电脑需要 **Python 3.11 或更新版本**。若未安装，先从 Python 官方网站安装，并启用 “Add Python to PATH”。本发行包已带预构建网页，**朋友使用时不需要 Node.js，也不需要 NAS**。
3. 双击 `启动大向AI-3D知识之城管理系统.cmd`。启动窗口会自动检查 Python 和本地服务，并打开浏览器。使用期间保留这个窗口；关闭窗口即停止服务。
4. 首次打开时，按页面提示**自己设置本机管理员账号**，然后选择自己的知识文件夹。没有默认账号、默认密码、默认仓库或预置知识内容。

默认访问地址：`http://127.0.0.1:8779/`。服务仅监听本机；不要把这个地址或端口直接映射到局域网或公网。如果端口已被占用，先关闭占用的程序，或者在启动前设置 `BLUEFIN_PORT` 为其他空闲端口。

## 仓库与知识之城

- 仅选择**本机文件夹**；当前版本读取其中的 **`.md` 文件**。网络共享/UNC 路径不接入。PDF、HTML、图片、录音等不会自动转换成正文。
- 仓库读取是只读的。文件仍留在你选定的位置；总控台、知识之城、目录、搜索和关联数据从可读取的 Markdown 生成。
- 知识之城沿用原版三维建筑、滨水岛屿、道路、中央地标和显示控制；每栋知识建筑对应当前仓库的真实文档。流畅度取决于电脑的浏览器与图形性能。
- 知识团队沿用人物头像和星轨布局；**一个一级分类对应一位成员**，点击可查看该大类及其子类的原文。初始至少保留 6 个席位：分类不足时余位保持空白，不计为成员；超过 6 类时继续扩展。分类来自朋友自己的 Markdown 元数据或顶层目录，不预置制作者的八类内容。后台定期重新读取本机仓库，页面也会刷新分类，新增分类及文档会自动补位。头像只是主题标识，不代表已接入独立工作的智能体。
- 隐私标记、凭据样式内容、常见备份/系统目录会被排除，但自动过滤不能代替你自己检查仓库。第一次接入前，请先确认所选目录中没有不想交给模型的资料。
- 程序不会替你创建或同步 NAS 仓库，也不会自动接管其他电脑上的资料。
- 总控台保留已确认的布局，但自动收集、去重、审核与每日入库回执不在朋友版运行；相应位置会明确标注未接入，不会用示例数据冒充实际结果。

## “问知识”的模型方式

- **Codex**：本机需要可执行的 Codex CLI，并完成你自己的 ChatGPT 登录；仅安装桌面图标不一定能让 CLI 可用。知识问答使用你当前选择的仓库，不使用安装包制作者的账号。
- **兼容 API**：由你填写自己有权使用的服务地址、模型和密钥。密钥不随安装包提供，网页提交后会清空，通常每次提问需重新输入；不同服务的费用、隐私条款由你自己确认。
- **WorkBuddy**：保留为可选接入方向；如果当前页面提示尚未配置，则暂时不能使用，请选 Codex 或兼容 API。不要把“可选择”误认为已经完成授权或联通。

选择 Codex 或兼容 API 提问时，问题以及为回答所需的知识片段可能发送给你所选的模型服务；它不是完全离线的 AI。请仅接入你有权处理的资料。

## 本机数据与分享边界

首次启动后，安装文件夹下会生成 `data/`，存放你的账号、设置、知识之城状态和问答历史。**不要把使用后的整个文件夹再打包给别人**；给其他人分享时，只发送最初的、未运行过的发行 ZIP。备份或迁移时也请把 `data/` 当作个人敏感资料保护。

这套程序是本机使用版本，不提供公网部署、多人协作或跨设备同步。忘记本机密码时，不存在制作者可代为取回的默认密码。

## 常见问题

- **双击后提示找不到 Python**：安装 Python 3.11+，重新打开命令行或重启电脑后再试。发行版不要求安装 Node。
- **浏览器没有自动打开**：保持启动窗口打开，手动访问上面的本机地址；如果窗口显示报错，先按报错处理。
- **端口被占用**：不要关闭其他正在使用的知识库服务；给朋友版指定另一个 `BLUEFIN_PORT`。
- **知识之城是空的**：先选择自己的仓库，确认里面有可读取的 `.md` 文件，再刷新扫描。刚安装时空城是正常状态，不代表预置了别人的知识。
- **Codex 不可用**：先单独确认 Codex 已安装并登录；也可以改用自己配置的兼容 API。不要将登录凭据或 API 密钥发送给制作者。
